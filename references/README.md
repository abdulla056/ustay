# References

The research behind Ustay's look-and-feel (Art Direction project, UST-32–38).
Gathering happened mostly in chat, so this folder is the distilled record.

## What's here

- **`SHORTLIST.md`** — the reference picks that decided the direction, each annotated with the
  *specific move* liked. This is the source of truth for taste.
- **`MOTION.md`** — motion references and the derived motion principles ("the easing is the brand").
- **`CURATED.md`** — the broader curated set of boutique-hospitality / editorial references (UST-33).
- **`full-site/`** — saved screenshots of the four shortlisted layouts (Woodvelly, Lunara,
  Villa Embrace, The Asteren).

## Direction (locked)

Editorial serif luxury · cinematic full-bleed photography · a **dark hero that tonally opens
into light editorial sections on scroll** · numbered/named editorial sections · minimal nav +
pill Reserve · carried by weighted, eased motion (layered parallax, scale-on-scroll, smooth
momentum). Being prototyped at `src/routes/prototype/` (UST-38).
